### ARM64源码编译 atinout

#### 编译步骤
```shell
# 更新依赖
sudo pacman -Syu
sudo pacman -S --needed base-devel git

# 克隆项目
git clone https://github.com/beralt/atinout.git
cd atinout

# 编译
make

# 安装
sudo install -Dm755 atinout /usr/local/bin/atinout

# 验证（输出 => /usr/local/bin/atinout）
command -v atinout
```

#### 测试串口

```shell
ls /dev/ttyUSB*
# 需要一个一个试
screen /dev/ttyUSB1 115200

# 输出 => OK
echo 'AT' | sudo atinout - /dev/ttyUSB1 -

# 输出4G信号
echo 'AT+QCSQ' | sudo atinout - /dev/ttyUSB1 -
```

### ARM64安装 iperf3（测试网速）

#### 服务端安装
```shell
sudo apt install iperf3

# 默认监听 TCP 5201 端口
# -s 表示服务端
# -D 表示以 daemon 方式后台运行
iperf3 -s -D
```

#### 客户端安装

```shell
sudo pacman -Syu
sudo pacman -S iperf3

# 测试上传（使用5条并行TCP连接，向121.229.215.177上传数据5秒，最后只输出总平均上传速度）
# -c 服务端IP => -c 121.229.215.177
# -t 5 表示持续测试5秒
# -P 5 表示创建5条并行连接进行测试
# -f m 设置速度显示单位 => Mbps（兆比特每秒）
iperf3 -c 121.229.215.177 -t 5 -P 5 -f m | awk '/^\[SUM\].*sender$/ {printf "%.2f Mbps\n", $(NF-3)}'

# 测试下载
iperf3 -c 121.229.215.177 -t 5 -P 5 -R -f m | awk awk '/^\[SUM\].*receiver$/ {printf "%.2f Mbps\n", $(NF-2)}'
```
