### 安装

#### Docker Compose脚本

```yaml
services:
  rabbitmq:
    image: rabbitmq:4-management
    container_name: rabbitmq
    restart: unless-stopped
    hostname: rabbitmq
    ports:
      # AMQP
      - "5672:5672"
      # Web 管理后台
      - "15672:15672"
    environment:
      RABBITMQ_DEFAULT_USER: admin
      RABBITMQ_DEFAULT_PASS: "123456"
      RABBITMQ_DEFAULT_VHOST: /
    volumes:
      - ./rabbitmq/data:/var/lib/rabbitmq
      - ./rabbitmq/log:/var/log/rabbitmq
```

#### 运行命令

```shell
docker compose up -d
```

#### 开启控制台

```shell
# 开启控制台
docker exec -it rabbitmq rabbitmq-plugins enable rabbitmq_management
# 插件列表
docker exec -it rabbitmq rabbitmq-plugins list
```

#### 命令大全

##### 状态

```shell
docker exec -it rabbitmq rabbitmqctl status
```

##### 用户

```shell
# 查看所有用户
docker exec -it rabbitmq rabbitmqctl list_users
# 新增test_user/123456
docker exec -it rabbitmq rabbitmqctl add_user test_user '123456'
# x修改密码 123456789
docker exec -it rabbitmq rabbitmqctl change_password test_user '123456789'
# 设置为管理员
docker exec -it rabbitmq rabbitmqctl set_user_tags test_user administrator
# 清除管理角色标签
docker exec -it rabbitmq rabbitmqctl set_user_tags test_user
# 查看用户权限
docker exec -it rabbitmq rabbitmqctl list_user_permissions test_user
# 授予 / 虚拟主机下所有资源的配置、写入、读取权限
docker exec -it rabbitmq rabbitmqctl set_permissions -p / test_user '.*' '.*' '.*'
# 查看 / 下所有用户权限
docker exec -it rabbitmq rabbitmqctl list_permissions -p /
# 撤销权限
docker exec -it rabbitmq rabbitmqctl clear_permissions -p / test_user
# 删除用户
docker exec -it rabbitmq rabbitmqctl delete_user test_user
```
