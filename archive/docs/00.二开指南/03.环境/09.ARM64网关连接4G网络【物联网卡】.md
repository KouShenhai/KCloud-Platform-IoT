# 4G通信模块（USB 网卡）

<font color="red">ARM64网关开启4G网络，需要使用4G通信模块！</font>

**EC200A 是移远通信（Quectel）推出的一款 LTE Cat 4 无线通信模块**‌，专为物联网（IoT）和 M2M 应用设计，最大下行速率 150 Mbps、上行 50 Mbps，支持 Windows 7/8/8.1/10/11、Linux、Android 等系统的 USB 驱动。

## 启用4G通信模块

ARM64网关是把 **GPIO 259** 配成输出，再写入逻辑值 **1**，连接到 **4G** 模块的电源使能端，用来给模块上电！（GPIO 259 接的是 **PWRKEY 开机键**，EC200A 4G通信模块引脚需要低电平脉冲）

<font color="red">每次重启ARM64网关，都需要手动启用4G通信模块</font>

```shell
cd /sys/class/gpio
echo 259 >export
echo out >gpio259/direction
echo 1 >gpio259/value
```

| 命令                             | 实际作用                                                  |
|--------------------------------|-------------------------------------------------------|
| `echo 259 > export`            | 让 Linux 提供 `gpio259` 控制接口。                            |
| `echo out > gpio259/direction` | 把引脚设为输出，默认先输出低电平。                                     |
| `echo 1 > gpio259/value`       | 写入逻辑 `1`。`active_low=0` 时输出高电平，`active_low=1` 时输出低电平。 |

## USB 网卡连接到网络（EC200A）

该命令用于控制 USB 网卡的网络连接。命令立即生效，最大响应时间为 **2 秒**。当 `<type>` 为 `3` 时，模块会自动保存配置。

### 命令与响应

| 类型   | 命令                                      | 响应                                                                        |
|------|-----------------------------------------|---------------------------------------------------------------------------|
| 测试命令 | `AT+QNETDEVCTL=?`                       | `+QNETDEVCTL: (<type> 的支持值列表),(<cid> 的支持范围),(<URC_en> 的支持值列表)`，随后返回 `OK`。 |
| 查询命令 | `AT+QNETDEVCTL?`                        | `+QNETDEVCTL: <type>,<cid>,<URC_en>,<state>`，随后返回 `OK`。                   |
| 设置命令 | `AT+QNETDEVCTL=<type>,<cid>[,<URC_en>]` | 成功时返回 `OK`，失败时返回 `ERROR`。如果错误与移动设备（ME）的功能有关，则返回 `+CME ERROR: <err>`。      |

设置命令中，方括号表示 `,<URC_en>` 为可选部分。

### 参数说明

| 参数         | 含义               | 取值与说明                                                                                                       |
|------------|------------------|-------------------------------------------------------------------------------------------------------------|
| `<type>`   | 操作模式，整数          | `0`：不连接网络。`1`：连接网络一次。`3`：自动连接网络。                                                                            |
| `<cid>`    | PDP 上下文标识符，整数    | 范围为 `1` 至 `15`，用于指定一个已定义的 PDP 上下文。该标识符在终端设备（TE）与移动终端（MT）的接口内有效，也用于其他与 PDP 上下文相关的命令。测试命令会返回允许的取值范围，最小值为 `1`。 |
| `<URC_en>` | 网卡状态主动上报开关，整数    | `0`：关闭上报。`1`：开启上报。开启后，模块通过 `+QNETDEVSTATUS: <status>` 主动报告网卡状态。                                             |
| `<status>` | 主动上报的网卡状态，整数     | `0`：网卡已断开网络连接。`1`：网卡已连接到网络。                                                                                 |
| `<state>`  | 查询命令返回的网络连接结果，整数 | `0`：连接失败。`1`：连接成功。                                                                                          |
| `<err>`    | 错误码              | 详见原手册第 12.5 节。                                                                                              |

### 示例

#### 测试命令支持的参数

```shell
AT+QNETDEVCTL=?
# +QNETDEVCTL: (0,1,3),(1-15),(0,1)
# OK
```

#### 通过上下文 ID 1 将 USB 网卡连接到网络一次

```shell
AT+QNETDEVCTL=1,1
# OK
```

#### 查询 USB 网卡状态

```shell
AT+QNETDEVCTL?
# +QNETDEVCTL: 1,1,1,1
# OK
```

## 电信物联网卡连接

```shell
# 确认AT入口
ls /dev/ttyUSB*
# 输出 microcom，就可以用它代替 picocom
busybox --list 2>/dev/null | grep -x microcom
# AT
(
    if systemctl is-active --quiet ModemManager; then
        systemctl stop ModemManager || exit 1
        trap 'systemctl start ModemManager' EXIT
    fi
    busybox microcom -s 115200 /dev/ttyUSB1
)
```

**确认模块读到了哪张卡**

```shell
AT
AT+CPIN?
AT+CIMI
AT+QCCID
```

| 命令         | 看什么            | 怎样理解                                                     |
|------------|----------------|----------------------------------------------------------|
| `AT`       | `OK`           | 已经和模块建立串口通信。                                             |
| `AT+CPIN?` | `+CPIN: READY` | SIM 已就绪。如果返回 `SIM PIN`，需要这张卡的正确 PIN。`READY` 本身不能证明套餐已激活。 |
| `AT+CIMI`  | 一串数字，即 IMSI    | 对中国大陆常见电信卡，看前五位。`46003`、`46005`、`46011` 都是中国电信常见的归属网络代码。 |
| `AT+QCCID` | `+QCCID: ...`  | 这是卡的 ICCID。用它向发卡方查具体套餐、激活状态和授权 APN。                      |

**确认当前实际接入的是电信 LTE**

```shell
AT+COPS=3,2
AT+COPS?
AT+CEREG?
AT+CGATT?
```

| 回执示例                   | 含义                                                               |
|------------------------|------------------------------------------------------------------|
| `+COPS: 0,2,"46011",7` | 当前接入 `46011` 中国电信，末尾 `7` 表示 LTE。之前扫网看到的 `available` 只说明附近能收到该网络。 |
| `+CEREG: 0,1`          | 看第二个数字。`1` 表示已在归属网注册，`5` 表示漫游注册，`2` 表示正在搜网，`3` 表示注册被拒。           |
| `+CGATT: 1`            | 已附着到分组数据服务。                                                      |

**<font color="red">电信卡注册被拒执行</font>**

```shell
# 电信配置
AT+CGDCONT=1,"IPV4V6","ctnet"
AT+CGDCONT?
AT+COPS=3,2
AT+CEREG?
```

**使用已经拨通的 CID 1，设置开机自动联网**

```shell
# 单次拨号
# +QNETDEVSTATUS: 1 => 已执行
AT+QNETDEVCTL=1,1,1
# 两个引号字段分别是 IP 类型和 APN
AT+CGDCONT?
AT+QNETDEVCTL?
# 保存自动拨号
AT+QNETDEVCTL=3,1,1
AT+QNETDEVCTL?
```

| `AT+QNETDEVCTL?` 的回执   | 现在该做什么                                                          |
|------------------------|-----------------------------------------------------------------|
| `+QNETDEVCTL: 1,1,1,1` | CID 1 已单次拨通。输入 **`AT+QNETDEVCTL=3,1,1`** 保存自动拨号。                |
| `+QNETDEVCTL: 3,1,1,1` | 自动拨号已设置，当前也已连接。直接验证 `usb0`。                                     |
| `+QNETDEVCTL: 0,0,0,0` | 如果已注册且 CID 1 的 APN 正确，先输入 `AT+QNETDEVCTL=1,1,1` 单次试拨，成功后再设自动拨号。 |

<font color="red">注意：退出AT，需要按 **Ctrl+A**，松开，再按 **Ctrl+X**。不用按回车。</font>

**验证4G网络**

```shell
ip addr
ip route show
ping -I usb0 223.5.5.5 -c 4
```
