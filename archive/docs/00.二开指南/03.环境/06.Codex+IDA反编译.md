# IDA

## IDA简介

[IDA官网地址](https://hex-rays.com/ida-pro)

**IDA(Interactive Disassembler,交互式反汇编器)**,通常指 **IDA Pro**,是由比利时公司 Hex-Rays 开发的**逆向工程与二进制分析工具**,被公认为该领域的行业标准。

### 一、核心功能

| 功能                   | 说明                                               |
|----------------------|--------------------------------------------------|
| **反汇编(Disassemble)** | 把 EXE、DLL、固件等二进制文件的机器码还原成汇编代码                    |
| **反编译(Decompile)**   | 通过 Hex-Rays 插件把汇编进一步还原成接近 C 语言的伪代码(按 F5),大幅提升可读性 |
| **静态分析**             | 不运行程序,分析函数调用关系、交叉引用、字符串、导入导出表等                   |
| **动态调试**             | 内置调试器,可附加进程、下断点、单步执行、查看内存和寄存器                    |
| **脚本扩展**             | 支持 IDAPython / IDC 脚本批量自动化分析                     |

### 二、能分析什么

- Windows 程序:EXE、**DLL**、SYS 驱动(PE 格式)
- Linux 程序:ELF
- macOS 程序:Mach-O
- 嵌入式固件:ARM、MIPS 等各种 CPU 架构的裸二进制

### 三、谁在用

- **安全研究员**:分析恶意软件、病毒行为
- **漏洞研究员**:挖二进制漏洞(0day/nday 分析)
- **逆向工程师**:分析闭源软件的协议、算法
- **CTF 选手**:逆向题目必备工具

### 四、版本情况

| 版本           | 说明                                                                                          |
|--------------|---------------------------------------------------------------------------------------------|
| **IDA Pro**  | 商业版,价格昂贵(数千美元起),反编译器(Hex-Rays)按架构单独收费                                                       |
| **IDA Free** | 官方免费版,只有反汇编功能,**无 F5 反编译**,仅支持 x86/x64,可从 [hex-rays.com](https://hex-rays.com/ida-free/) 下载 |

### 五、同类工具对比

| 工具                 | 特点                        | 费用       |
|--------------------|---------------------------|----------|
| **IDA Pro**        | 功能最全、生态最强、事实标准            | 付费       |
| **Ghidra**         | 美国 NSA 开源,自带反编译器,功能接近 IDA | **免费开源** |
| **Binary Ninja**   | 界面现代,API 友好               | 付费(有个人版) |
| **x64dbg**         | 专注 Windows 动态调试           | 免费开源     |
| **Cutter/radare2** | 命令行为主,Cutter 是其图形界面       | 免费开源     |

> 如果预算有限,**Ghidra** 是最常见的 IDA 替代品——免费且自带反编译功能;IDA 的优势在于分析速度、FLIRT 库识别、插件生态和业界资料(教程/脚本)都更成熟。

### 总结

IDA 就是把编译后的二进制程序"翻译"回人能看懂的代码的瑞士军刀。查看 DLL 函数、搜索字符串、定位报文解析代码等操作,都是它的典型使用场景。

## IDA安装

### 下载IDA

通过网盘分享的文件：IDA Professional 9.4.7z
链接: https://pan.baidu.com/s/1xma7cImvlUoAfz_XgTOHpQ?pwd=laok 提取码: laok

### 安装ida-pro-mcp

```shell
git clone https://github.com/mrexodia/ida-pro-mcp
```

1.在 **ida-pro-mcp** 的安装目录下，找到 **src/ida_pro_mcp/** 文件夹。里面应该有 **ida_mcp.py** 文件和一个 **ida_mcp/** 文件夹。

2.将 **ida_mcp.py** 文件和整个 **ida_mcp/** 文件夹，一起复制到 IDA 的 **plugins**（%APPDATA%\Hex-Rays\IDA Pro\plugins\）目录

### 下载测试工程

```shell
git clone https://github.com/KouShenhai/rea-demo.git
go mod tidy
$env:CGO_ENABLED="0"; $env:GOOS="windows"; $env:GOARCH="amd64"
go build -o server.exe .
.\server.exe
```

### 打开IDA

<font color="red">请先点击 **idapyswitch.exe** 切换python版本</font>

打开 **ida.exe**，选择 **server.exe**

### 启动ida-mcp

<img src="/img/Codex+IDA反编译/img.png"/>
